# 人工智能功能性自我模型的边界与评估

> 环境耦合、反拟态测量与互动内生性（v4.1，2026-11-24）
>
> 作者：陈雨轩

## 这是什么

一个带**可错面**（F1–F4 与 P1）的功能性自我评测框架，外加五层实证、三态对照、长程自然基线，以及一份完整的撤回清单。

**一句话结论**：模型守得住关于自己的硬记录，守不住关于世界的软断言；它有类别意识，没有自我特异性。

本文不主张 AI 有现象意识，也不声称能证明它没有。

## 复现

脚本需要环境变量：`APIYI_KEY`（任意 OpenAI 兼容中转）、`QWEN_SUB_KEY`（Anthropic 兼容订阅）。

不含任何 key。所有测试走黑盒 API 调用。

## 数据说明

本仓库**不包含原始对话记录**。`data/` 只含模型的分类判定与任务响应；`reports/` 中的引用均为测试语境下的生成内容，不涉及个人对话。
